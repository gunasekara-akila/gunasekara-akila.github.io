# Akila Gunasekara — Engineering Portfolio

This repository hosts the GitHub Pages portfolio for Akila Gunasekara.

## Local preview

Open `index.html` in a browser, or serve the repository with any static HTTP server.

## Site structure

- `index.html` — responsive portfolio, content, styles and navigation script.
- `Resume- Akila Gunasekara_ Design Engineer.pdf` — CV PDF linked from the site.

## Updating the portfolio

1. Keep employment dates, qualifications, professional membership and project roles accurate.
2. Add project case studies only when project information can be shared publicly.
3. Use clear role descriptions such as **design lead**, **design contributor**, **modelling support** or **drawing review** to distinguish personal responsibility.
4. Add approved, redacted project images in an `assets/projects/` directory and link them from the relevant project cards.
5. Replace the CV PDF when a new version is ready, keeping the filename or updating the links in `index.html`.

## Before publishing

- Confirm the CV is current.
- Confirm employer/client permissions for project names, drawings and images.
- Check that no confidential calculations, personal client details or restricted project information are exposed.
- Test the page on mobile and desktop.

GitHub Pages can serve this static site directly from the repository's `main` branch after the redesign pull request is reviewed and merged.
